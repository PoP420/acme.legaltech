## Implementation Order

1. **Plans 1 & 2** — Complete existing stubs (review detail, obligation detail). Highest user impact.
2. **Plan 3** — AI extraction review. Unique AI differentiator, no backend changes needed.
3. **Plan 4** — Portfolio dashboard. Executive visibility, uses existing list endpoints.
4. **Plan 5** — Contract living view. UX improvement, extends existing detail page.
5. **Plans 6 & 7** — Playbook evaluation and approval calculator. Medium impact, some backend enhancements helpful.
6. **Plans 8, 9 & 10** — Critical dates, audit trail, clause comparison. Advanced features with backend gaps.

## Key Convention

All plans assume:
- Angular inline templates (no `.component.html` files)
- Hand-written `RestService.request()` calls (no ABP generated proxies)
- `ListService` from `@abp/ng.core` for paged queries with `hookToQuery`
- `confirm()` for confirmation dialogs (upgrade to `ConfirmationService` later)
- Permission guards via `*abpPermission` directive
- Lazy-loaded routes via `loadComponent` with dynamic imports
