# Delivery Roadmap and Milestones

## Delivery approach

Business-Ready v1 is delivered in four phases over 6 to 12 months.

## Phase A: Foundation (Month 1-2)

- Platform conventions and bounded contexts
- Expanded contract baseline and persistence model
- Permission tree and route scaffolding
- Initial migrations and quality pipeline

Exit criteria:

- Core structure and shared standards established
- Foundation module quality gates passed

## Phase B: CLM Core (Month 2-5)

- Contract intake and repository
- Clause library and playbooks
- Review workflow
- Obligations and renewals

Exit criteria:

- End-to-end contract lifecycle operational for tenant users
- Reporting baseline available

## Phase C: Operations and Administration (Month 5-8)

- Search, reports, dashboards
- SaaS administration and plan packaging
- File and evidence management
- Identity and OAuth admin workflows

Exit criteria:

- Operational governance and host controls production-ready

## Phase D: Intelligence Assist (Month 8-12)

- OCR and extraction orchestration
- Risk scoring suggestions
- Human-in-the-loop correction workflow
- RAG-backed repository assistant (controlled scope)

Exit criteria:

- AI assist available as opt-in tenant capability
- Audit and acceptance tracking for AI decisions in place

## Program-level deliverables

- Product requirement baseline with traceability
- Numbered implementation plans by module
- Test and verification matrix per module
- Operational runbook and monitoring checklist
